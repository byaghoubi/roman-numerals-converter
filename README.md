# Roman Numerals Converter

A simple, interactive web application that converts numbers to Roman numerals and Roman numerals to numbers.

## Features

- Convert numbers to Roman numerals.
- Convert Roman numerals to numbers.
- Validate user input.
- Display clear error messages for invalid inputs.
- Responsive user interface.

## Built With

- HTML
- CSS
- JavaScript
- Tailwind CSS

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/byaghoubi/roman-numerals-converter
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
